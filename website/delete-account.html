Suppression de compte

Vous souhaitez supprimer votre compte Résumé+ ? Découvrez comment faire votre demande. La suppression est immédiate et irréversible.

Procédure

Comment supprimer votre compte

Suivez ces étapes pour demander la suppression définitive

Étapes à suivre

  1. Connectez-vous à votre compte Résumé+ sur l'application mobile.
  2. Accédez au menu Paramètres Supprimer mon compte.
  3. Lisez attentivement les informations concernant les données qui seront supprimées.
  4. insérez votre numéro de téléphone et Confirmez votre demande. Un code OTP à 4 chiffres vous sera envoyé par SMS
  5. Saisissez le code OTP reçu pour confirmer la suppression définitive de votre compte.
  6. Votre compte est immédiatement et irrévocablement supprimé de nos serveurs

Attention : La suppression est définitive et irréversible. Une fois le code OTP validé, votre compte et toutes vos données personnelles sont immédiatement effacés de nos serveurs. Les achats effectués, abonnements en cours et résumés achetés ne seront plus accessibles. Aucune restauration n'est possible.

Conséquences

Ce que vous perdez

Impact de la suppression immédiate de votre compte

  • Accès perdu : Vous ne pouvez plus vous connecter à l'application Résumé+.
  • Achats perdus : Tous les résumés que vous avez achetés deviennent inaccessibles. Aucun remboursement n'est effectué pour les achats déjà réalisés.
  • Abonnement perdu : Si vous avez un abonnement actif au service QCM/Exercices, il est résilié sans remboursement.
  • Données perdues : Votre historique, vos préférences et vos réglages sont supprimés.
  • Notifications : Vous ne recevez plus de notifications de l'application.

Irréversible : Une fois le code OTP confirmé, la suppression est définitive. Aucune donnée ne peut être restaurée. Si vous souhaitez réutiliser Résumé+ après suppression, vous devez créer un nouveau compte — les achats et l'historique précédents ne seront pas récupérables.

Recréer un compte

Vous pouvez recréer un compte Résumé+ à tout moment après la suppression. Cependant :

  • Vous devez suivre le parcours d'inscription complet (OTP, profil, etc.).
  • Les résumés précédemment achetés ne sont pas restaurés.
  • L'historique et les préférences sont réinitialisés.
  • Si vous utilisez le même numéro de téléphone, un nouveau compte est créé sans lien avec l'ancien.

Questions fréquentes

Puis-je annuler ma demande après avoir soumis le code OTP ?

Non. Dès que vous validez avec le code OTP, la suppression est immédiate et irréversible. Aucune annulation ni restauration n'est possible.

Que se passe-t-il si j'ai un abonnement actif ?

Votre abonnement est résilié automatiquement. Conformément à nos conditions d'utilisation, aucun remboursement n'est effectué.

Combien de temps faut-il pour que la suppression soit effective ?

La suppression est instantanée. Dès que vous saisissez le code OTP et confirmez, votre compte et toutes vos données personnelles sont immédiatement effacés de nos serveurs.

Puis-je réutiliser mon numéro de téléphone après suppression ?

Oui, vous pouvez créer un nouveau compte avec le même numéro de téléphone. L'ancien compte et son contenu ne seront pas restaurés.

Que faire si je n'arrive pas à supprimer mon compte depuis l'application ?

Contactez-nous par email ou téléphone. Nous traiterons votre demande manuellement après vérification de votre identité.
